Registro de testigo electoral

Este formulario permite enviar los datos necesarios para coordinar el puesto y la mesa asignados. El registro quedará pendiente de validación por el equipo autorizado.

Tratamiento de datos personales: la información se utilizará exclusivamente para gestionar y verificar el registro operativo de testigos electorales. No incluyas afiliación política, preferencias electorales ni información de terceros. El acceso queda restringido al personal autorizado. Al enviar, autorizas el tratamiento de los datos consignados para esta finalidad.
